# Sistem Pencatatan Hasil Panen Digital

**Deskripsi:**
Proyek ini adalah program Python sederhana untuk menghitung total pendapatan dari hasil panen. Program ini juga dilengkapi dengan fitur perhitungan diskon sebesar 10% apabila total pendapatan kotor mencapai lebih dari Rp 1.000.000.

**Cara Menjalankan Program:**
1. Pastikan Anda memiliki Python yang sudah terinstall.
2. Jalankan file `panen.py` melalui terminal dengan perintah: `python panen.py`
3. Masukkan berat panen dan harga per kg sesuai instruksi di layar.
